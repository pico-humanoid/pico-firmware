## 已整理到文档的结论

- 用现成 NUCLEO-G474RE 作为核心板，外接三颗 TJA1051T/3，三个小终端开关按通道布置。
- 底板使用电源板已有的 5V/2A，机载计算机保留独立 19V 模块；不再把额外 48V→5V 模块写成必需。
- 起步使用经典 CAN；不同速率的 BMS 与关节分路。收发器型号和控制器能力不能代替整链 CAN FD 验证。
- 现用动力电源板不带电机 CAN 集线功能，动力和通信线束分别规划。
- 电源板参数、电池原有参数、选脚、设计检查与实物验收分别记录；未确认的实际值不填成默认成功。
