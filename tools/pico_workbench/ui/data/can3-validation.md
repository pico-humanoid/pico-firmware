# 电池与电源板 CAN3 配置及操作

本地更新：2026-11-09。适用：桌面“PICO 开发环境”，项目 `/mnt/data/STM32Projects/PICO_CAN`。导入仓库基线 b5f244c；本页记录本地修改，未推送远端。

## 已完成的配置

电池 BMS、电源板及 Dual 双设备读取均改用 **FDCAN3**，包含初始化、GPIO 复用、中断、收发后端、健康计数和串口报文标识。原 CAN1 内部回环、外部双向测试保持原通道。

| 项目 | 当前配置 |
| --- | --- |
| MCU 发送 | PA15，CN7-17，AF11 → 收发器 TXD |
| MCU 接收 | PA8，CN10-23，AF11 ← 收发器 RXD |
| 底板 | U3 / TJA1051T/3；CN5、CN6 为同一 CAN3 总线 |
| 底板总线接口 | 1 脚 CANH、2 脚 CANL；R3/SW3 为本路 120 Ω 端接 |
| 设备速率 | BMS=500K；Dual=500K；Power 单独可选 500K 或 1M，匹配设备实际速率 |
| 调试与日志 | 保留 PA13/PA14 的 SWD；ST-LINK 虚拟串口 115200 / 8N1 |

两个设备共享 CAN3 时均须已工作在 500K。普通读取镜像不会写设备参数或自动改设备速率。MCU 的 TX/RX 只接收发器逻辑侧，不能直接接 CANH/CANL；底板供电按“底板接线”页核对。

## 直接使用

1. 打开桌面 **PICO 开发环境**，已打开的旧窗口需关闭后重开。
2. 电池单独读：选 **电池 BMS 只读 · CAN3 · 500K**；电源板单独读：选对应 CAN3 / 500K 或 CAN3 / 1M；同时读：选 **BMS + 电源板 · CAN3 · 500K**。
3. 已生成对应 ELF/BIN；连接 ST-LINK，点 **04 烧录当前实验**。更改桌面标签不会改变板内旧固件，需要烧录新镜像。
4. 设备线束接底板 **CAN3 的 CN5/CN6**；如用独立收发器，逻辑 TXD/RXD 改接 PA15/PA8。
5. 选择开发板日志串口，点 **05 采集开发板日志**，再按开发板 RESET。启动行应含 `channel=FDCAN3`，8 列 CSV 的 channel 列应为 `FDCAN3`。
6. 检查 `TX_DONE`、`RX`、BMS/POWER 解析及健康计数，按设备验收说明完成实物验证。设备读取模式不会套用旧 100 帧自动 PASS 判据。

**09 底板接线 / 固件新功能** 中可查看更新后的接线、通道用途和本页。**01 打开 VS Code 对应项目** 会打开当前配置的工作区，使用对应 CAN3 镜像及调试路径；**03 编译当前实验** 可重新构建。
