Ubuntu 串口通常为 /dev/ttyACM* 和 /dev/ttyUSB*。若提示权限不足，使用原 Ubuntu 开发环境的 USB 权限安装入口，再重新连接设备。适配器协议仅支持原 USBCAN V2.12 / Waveshare USB-CAN-A；CH340 芯片名称本身不能证明协议兼容。
