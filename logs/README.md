## 分片时间索引压缩

`g474/20261101-164647-power-read-1m-fresh.chunks.jsonl.gz` 是原 JSONL 的无损 gzip 压缩版。原分析 JSON 中的 SHA-256 对应**解压后的原文件**，而证据清单的 SHA-256 对应**实际发布的 gzip 文件**。可直接核对：

```bash
gzip -dc logs/g474/20261101-164647-power-read-1m-fresh.chunks.jsonl.gz | sha256sum
# 992f95d7277f372cb720fd6149aa05c827909f7f1dbd8b54b0545a19ec2b8700
```

- 本地中间实验日志、清理前整包备份、手册裁剪图和下载失败文件。

这些材料仍保存在本地忽略目录；GitHub 克隆不包含它们。公开结论不依赖读者取得这些本地归档。原仓库已跟踪的历史材料保持不动。

日志内可能保留采集当时的绝对路径、串口编号和历史计数，这是原始记录，不代表其他电脑应使用同一路径。新操作应从文档中的构建/采集入口开始，并识别本机串口。

**注意：** 串口采集完成不是设备 PASS；UART 提交不是 CAN TX_DONE；历史通过不是当前通过；模拟 65 秒不是实机 65 秒。USB-CAN 日志不提供与 G474 控制器相同的 TEC/REC 遥测。
