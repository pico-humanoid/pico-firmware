# 单 / 双电机位置与速度交互跟踪示波器

入口：PICO开发控制台 → 实验中心 → 单机调试 → 交互跟踪示波器 · 位置 / 速度，或双机联调 → 双机交互跟踪示波器。原生Tk窗口；Windows与Ubuntu使用同一源代码，本轮只在Windows离线验证，未进行电机或Ubuntu实机测试。

## 操作

1. 单机选择RS10P ID1或RS00 ID2；双机选择“双电机交互跟踪”，两台并接CAN1、ID分别为1和2，保持总线终端与已有双机成功实验一致。TX PA12 / RX PA11、1Mbps，保持已有成功接线。固定外壳、空载。
2. 点击“1 编译并烧录”，再点击“2 连接并复位”。等待停止确认、3次UID及5次稳定位置采样完成，状态进入READY；连接本身不会使能。
3. 选择位置或速度模式，设置运行时长（秒）及初始值，点击“3 开始跟踪”。拖动滑块和数值输入双向同步，默认只更改待提交目标，再点击“应用目标”才发送。
4. 可勾选“编辑后自动应用”，在已经手动开始的会话中，编辑停顿200ms后合并发送最新目标；拖动本身不会使能。按钮“设为0”只将待提交角度或速度改成0，是否立即发送取决于自动应用选项；它不修改机械零位，也不能代替立即停机。
5. 点击“立即停机”，确认stop_confirmed=1与target_cleared=1。切换模式或再次运行：先停机、断开，再连接复位。停机未确认应使用实物断电措施。

## 可调范围

| 模式 | 滑块与输入框 | 固件设置 | 自动停止 |
|---|---|---|---|
| POS / run_mode=5 | 相对起点角度±30°；限速0.01–0.3rad/s | 限流固定0.5A | 使能后1～300秒，可设置 |
| SPD / run_mode=2 | 速度目标-0.3～+0.3rad/s，正负控制方向 | 限流0.5A，加速度0.5rad/s² | 使能后1～60秒，可设置 |

0.3rad/s约2.9rpm。位置滑块步进0.1°，速度滑块步进0.01rad/s；数值框支持更细输入，最终角度以0.001°、速度以0.001rad/s发送。初次先在0°、限速0.2rad/s开始，再改±2°；速度模式先0rad/s，再尝试±0.1rad/s。SPD不保持位置；POS中的“限速”是速度上限，不是独立速度轨迹指令。

位置模式实际位移超过32°请求停机；速度模式的位移保护为所设时长×0.3rad/s＋10°余量，不再固定为60°，因而可以进行较长的连续转动。两种模式实测速率超过0.5rad/s、Iq超过0.8A请求停机。心跳、运行反馈或实际参数采样中断500ms，以及CAN/UART异常、UID变化、位置突跳，均中止并请求停机。软件保护离散采样，不能保证物理位置绝不越界。起点来自本次实测位置，不改机械零位。

## 波形和记录

POS显示提交角度、回读确认目标、实际角度及可切换误差；速度面板显示正负限速线和实际速度。SPD显示实际位移，以及提交速度、回读确认速度目标和实际速度。实际Iq继续显示并写入CSV，作为保护与负载观察，不再提供电流目标控制。

波形最多10Hz刷新，隐藏面板不重绘。采样和原始文件完整接收，冻结显示不影响心跳。实际位置、Iq、速度依次读取，不是同步采样，内部按响应轮询、通常每秒数十组，逐帧执行保护；为容纳双机115200串口带宽，每台遥测最多10Hz输出，原始board.log完整保留实际输出。适合低速阶跃跟踪观察，不用于测量电机内部高速环路带宽。

图显示最近20秒，CSV保存当前会话最多12000组。角度°、速度rad/s、电流A；不适用字段为空。为兼容旧日志解析，CSV仍保留旧Iq目标字段，新固件不产生这些目标值。重新复位/起点清除旧数据。原始board.log、commands.jsonl、settings.json、result.json在logs/motor-tuning-时间保存；不自动判定电机合格。

## 固件和兼容性

RS10P-Tuning / RS00-Tuning / Motors-Tuning使用MotorTuning固件、CAN1/1Mbps、固定RobStrideSPC d8451a4适配层。协议5：ARM携带模式、目标、限速和时长毫秒；ARM2携带双机目标及共同模式/时长，SET2成对更新双机目标；单机仍由SET或SETSPEED更新目标；所有目标逐项参数回读后才标为已应用。仅使用0x7005、0x700A、0x7016、0x7017、0x7018、0x7022，及UID、启停和只读采样。不发送保存、改ID、波特率、机械零位或标定命令。

旧协议3/4的交互固件不兼容，必须重新编译烧录；新上位机会拒绝旧固件，避免运行时长或目标参数混用。零电流使能和0.7A入口已退役；保留共用代码及原始历史日志，第三台0.5A已起转按用户报告记录。

## 双机联调与时长

双机使用相同模式和共同运行时长，位置、限速或正反转速度分别用两组滑块设置；两幅示波器并排显示，各自CSV包含motor_id列。电机ID1和ID2各自读取UID与起点，不复用另一台的起点。不能用相同ID区分两个物理电机。

开始时同时核对两台READY、UID不重复及所有输入；一项非法就整条命令拒绝。两台均完成使能前参数回读才释放使能，两台均完成使能后复核才释放非零目标。共用CAN总线依次发送，属于联调，不宣称机械同步或硬件同时动作。

时长从使能提交开始由MCU计时，运行中锁定时长输入，更新滑块不重新计时。默认位置60秒、速度3秒，可以在开始前修改，支持毫秒精度的秒数输入。到时、手动停止、心跳丢失或任一台异常，均请求两台停机。只收到一台停止反馈不能判定双机已停止；两台停止及目标清理结果分别记录，汇总状态要求两台确认。长时间速度运行会连续转动，应仅在已确认允许连续转动的空载条件下执行。

## 疑似受阻报警

起动后留出1秒观察期；目标速度绝对值至少0.08rad/s，或位置误差超过2°时，若实际速度绝对值低于0.02rad/s、实测Iq至少0.4A，且新鲜完整采样连续满足700ms，则报SUSPECTED_OBSTRUCTION并请求停机。条件消失则清除累计时间，短暂电流峰值不触发此报警。双机按现有联动机制请求两台停止；上位机红色提示保留到重新连接复位。

这是基于电流与速度的疑似堵转检测，不是力传感器，不能保证检测所有阻力，也不能作为人员防碰撞保护。小于阈值的阻力、仍能运动的受阻或反馈异常可能无法按此条件识别；原有过流、超速、通信超时等保护继续生效。

## 电流与界面调整（最新）

协议6新增限流设置：每台在开始前通过滑块或数值框选择0.1–0.7A，默认0.5A；开始后锁定限流，需停止、断开并重连后调整。使能前写入0x7018并回读确认，上位机显示实际Iq及回读限流。这里设置的是电流上限，不是强制电机持续输出指定电流。实测Iq超过1.0A请求停机；疑似受阻的电流条件改为所设限流的80%，其余持续时间和速度条件保留。

实验界面上下分隔条可调整控件区与波形/日志区高度，双机左右分隔条可调两台波形宽度。应用共享主题的窗口允许拖动边框调整尺寸，Ctrl + / Ctrl - 调整标准界面字号；显式设置字号的标题和图中文字保留其专门样式。

## 最新限流上限：5A

用户指定将每台可设置限流上限扩展到5A；默认仍为0.5A，开始前分别设置并在使能前回读确认，运行中锁定。5A是可选上限，不是默认输出或额定持续电流；RS00的额定负载相电流峰值为4.7Apk，5A高于该额定数值。软件实测Iq过流阈值为min(6A，所设限流×1.2＋0.1A)，受阻检测仍以所设限流80%和低速持续条件判断。此前0.7A上限及固定1A过流阈值已被本节替代。本轮未进行5A实物测试。

## 最新默认限流：按型号额定值

RS10P默认与可调上限均为5.3A；RS00默认与可调上限均为4.7A；双机分别应用。此前统一5A上限和0.5A默认已被本节替代。上位机与固件均按型号限制，并在使能前写入、回读确认；本次未进行额定电流实物测试。额定值需要配合对应手册的散热与工作条件，不代表未安装散热板也可以持续满载。
