# 每周工作汇总

按周一至周日归档，周报记录本周完成的工作、实验结果、待解决事项和后续计划。进行中的一周注明统计截止日期，同周新增进展继续更新该周文件。

## 周报索引

| 周期 | 统计截止 | 状态 | 主要进展 |
| --- | --- | --- | --- |
| [2026-10-26—2026-11-01](2026-10-26.md) | 2026-10-27 | 本周进行中 | 内部回环通过；外部单触发返回 100 帧已核对；工程与日志归档；文档分层与开发分工整理 |

## 后续如何记录

1. 复制[周报模板](template.md)，以该周周一命名，例如 `2026-11-02.md`，填写周期和统计截止日期。
2. 写明本周新增成果，实验附原始日志或报告，代码与文档附文件或版本链接；规划、实现、模拟验证和实机验证分别标注。
3. 更新本页索引，最近一周放在最上方，并更新仓库首页的本周入口。
4. 周末核对后将状态改为“已归档”，保留历史记录。没有证据的往期进展在取得记录后再补充。
