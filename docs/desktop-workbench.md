# PICO 开发控制台 · 2026-11-24

Windows x64 和 Ubuntu 24.04 x86_64 原生版，附日志查看器、固件源码、历史实验入口和使用说明。解压后运行平台对应的“打开开发控制台”。Windows 编译、烧录按附带说明配置现有 STM32 工具；Ubuntu 包含 ARM 编译及 OpenOCD 工具。

- 实验中心 → 保护验证 → 七电机实机状态机，支持阻尼 Kd 滑块和 CSV 采样。
- 调试预留可直接请求零力矩或阻尼。后台先完成自检、停机确认和逐台使能；停机命令或心跳超时可取消。上电自检通过后，仍需手动启用才进入零力矩。站立、下蹲及独立调试功能留待实现。
- 七电机窗口加入「状态转换图」，图中包含开机到零力矩的路径。
- 七电机可直接烧录的镜像在 project/firmware-images，接线、调节和源码说明在 project/fsm7。
- 移除停机位置诊断窗口、快捷命令和实验配置。联动停机等保护仍保留；旧日志可继续用日志查看器打开。
- 此版软件构建与界面测试不包含实物烧录或运动验收。
