## 固件侧自行完成

| 工作 | 固件侧负责的内容 | 何时需要协助 |
| --- | --- | --- |
| 外设与驱动 | 阅读 G474、开发板及收发器手册，核对复用与时钟，配置 FDCAN / UART / GPIO，完成编译、烧录与台架验证 | 最终原理图或实物接线与现有记录不一致时，和电气负责人核对 |
| 协议与编解码 | 阅读现有电机、BMS、电源板协议，整理 ID、字节序、缩放、单位、校验和报文样例，实现并测试解析 | 文档版本冲突或字段有歧义时，整理具体问题向设备供应方核实；需要采购联系时请设备负责人协助 |
| 设备配置与查询 | 读取或配置设备 ID，检查 BMS 实际位速率和配置能力，查询电源板 ID 与上报周期 | 设备未到位时请负责人提供可用时间；接入供电和改动设备配置前核对实际条件 |
| 软件与工具 | 完成队列、时间与有效性、状态机、故障检测、看门狗、参数存储、模拟回放和日志采集 | 整机动作、运行范围和恢复需求需要联合确定 |
| 上下位机协议草案 | 先拟定字段、单位、序号、版本、帧格式、校验、时间语义和启停流程，提供电脑端示例 | 与控制侧核对控制模式、目标语义、周期及更新规则后确定接口 |
| 实验记录 | 固件侧采集原始请求 / 回复、生成解析示例，保存构建版本、接线、设置、计数与结果 | 他组已有对应原始记录时直接引用；真实设备测试由相关负责人配合 |

BMS 文档默认 500 kbit/s 与实物配置分别核对；电源板 Type03 电流字段由固件侧先核对文档和样例，仍有歧义再询问供应方。这些属于固件调研与验证任务。

## 需要其他组补充或共同确定

| 对接方 | 需要确认的项目专有信息 | 固件侧先准备 |
| --- | --- | --- |
| 机械组 | 装配后逐关节型号、转轴正方向、可重复的零位姿态、机械活动范围、额外传动关系与装配版本 | 按已有 14 关节名称建立映射表，阅读电机参数，拟定零位标定流程并实现参数保存；具体标定值通过实机测量取得 |
| 电气组 | 最终原理图与连接器定义、各支路实际接线、终端位置、供电时序、急停接法与信号行为，以及相对既有引脚方案的变更 | 提供已选引脚、外设需求与初始 CAN 分路，整理设备 ID 分配草案并检查冲突 |
| 控制与上位机组 | 控制模式与目标含义、控制周期和允许延迟、完整 / 部分关节更新规则、运行限值、启动与恢复需求 | 提供上下位机接口和状态机草案；共同确定物理接口、指令有效期、故障处置和最终限值 |
| 传感器选型 / 安装负责人 | 实际选用型号、接口接线、安装位置与方向、已有标定记录；选型尚未确定时注明状态 | 自行读手册、确定字段和换算、编写驱动与时间处理；依据控制需求讨论采样率，完成采集与标定验证 |
| 控制、电气、机械与测试联合 | 结合姿态和硬件能力确定故障动作、执行方、通信不可用时的处理、解除 / 重新使能条件、测试支撑与运行范围 | 提供故障检测逻辑、诊断记录与处置方案，在模拟环境验证转换后组织实机核对 |

先解决当前测试所需的信息，其余逐步补齐。草案与测试配置可支持协议库、模拟器和软件框架开发；接入真实设备或执行运动前，确认对应条件。

| 工作表 | 已填内容与后续用途 |

## 记录方式

沿用原仓库的资料与协作方式即可。提供文件路径、版本或 commit 链接；发生接口变更时补充影响范围。固件侧维护引用与配置，实际验证后更新结果。

```markdown
- 对接事项：本轮需要确认的具体问题
- 已有依据：文件 / 版本 / 链接
- 固件侧草案或已完成检查：待填写
- 需对方确认的内容：待填写
- 结论 / 负责人 / 日期：待填写
- 如暂未确定，下一步与预计时间：待填写
```

协议解析、时间关系、构建与实验结果由固件侧持续完善；整机故障动作由相关负责人共同约定，通信恢复后按已确定的条件重新使能。
