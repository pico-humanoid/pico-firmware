# Robot14 七台电机调参流程（操作者版）

适用：标准 Robot14 固件、CAN2 接 1–7（RS00 1–3 / RS10P 4–7）、CAN1 接电源板/BMS、空载或可靠支撑。全程可在“14电机整机可视化调参”窗口完成。

## 0. 开始前

- 机械：电机空载或台架固定；准备独立急停/断电；不要用手触碰输出轴。
- 电气：CAN2 1 Mbps、CAN1 500 kbps、共地、两端 120 Ω；电源板 VMBUS 约 53 V。
- 串口：只开一个程序占用 `/dev/ttyACM0`；不要同时开旧单/双机窗口。
- 固件：标准 Robot14（含总线隔离修复）。**刷过 SWAP 诊断固件的话先烧回标准镜像。**

启动：

```bash
cd "/home/zjy/Systems and Control/PICO/pico-firmware"
python3 tools/pico_workbench/ui/native.py --robot14
```

## 1. 连接（只读）

1. 选 `/dev/ttyACM0`，点“连接（只读 / 不复位）”。
2. 确认 UID、160 MHz、保护签名校验通过。
3. 表格 14 行：ID1–7 有位置/速度，ID8–14 显示 `—`。
4. 连接、刷新、改数值、拖滑块都不发送命令。

## 2. 单台基准（先 ID1，再 2–7）

### 2.1 零力矩使能

1. 选 ID1；“本次使能时长”设 **30–60 秒**（先短后长）。
2. 勾选安全确认，点“使能选中（零力矩）”，核对弹窗。
3. 等表格 **ACTIVE / M2**；观察 3–5 秒：位置不漂、速度≈0、无故障。
4. 不输入任何目标时，零力矩不会出力。

### 2.2 位置保持（Kp / Kd）

1. 把 **p 填成表格当前读到的位置**（不是 0），v=0，τ=0。
2. 先 **Kp=0.5、Kd=0.1**，点“应用目标到选中”。
3. 观察 1–2 秒：位置应基本保持；有低频晃动就把 Kd 加到 0.2–0.3；有高频抖动就把 Kp 降 0.2–0.5。
4. 逐步把 Kp 提到 **1.0 → 2.0**（RS00 摩擦大，可能需要 1.5–2.5；RS10P 一般 0.5–1.5）。
5. 判定：位置误差稳定在 0.02–0.05 rad 内、无持续嗡嗡声/抖动。**出现自激振荡立刻停止选中。**

### 2.3 位置阶跃

1. 以当前 p 为基准，p 加 **+0.03 rad**，其余不变，应用。
2. 等 1–2 秒稳定，再加到 +0.05、+0.1；然后逐级回到基准。
3. 判定：平滑移动、1 秒内基本到位、超调 <10–20%。超调大→降 Kp 或加 Kd；跟不上→加 Kp。
4. 单次阶跃先不要超过 **0.15 rad**。

### 2.4 速度模式

1. p=当前位置，**Kp=0**，Kd=0.5，v=+0.1，τ前馈=0.05，应用。
2. 观察 1 秒，确认转向正确、速度稳定；再试 v=0.2/0.3、τ前馈=0.1/0.15。
3. 反方向 v=-0.1 → -0.3 重复。
4. 判定：实际速度与指令同号、偏差约 ±0.03–0.05 rad/s；RS00 摩擦大，通常需要 0.1–0.15 N·m 前馈才能跟上；RS10P 可以小一些。
5. 速度一直上不去→加 τ前馈；来回摆→降 Kd 或降 v。

### 2.5 力矩模式

1. p=当前位置，**Kp=0**；纯力矩用 Kd=0，安全起见先用 **Kd=0.5** 限速。
2. v=0，τ=+0.05，应用 0.3–0.5 秒；观察力矩反馈、速度和声音。
3. 再试 τ=-0.05；然后逐步到 **0.1 / 0.2**（RS00）、**0.2 / 0.4**（RS10P）。
4. 判定：力矩反馈同号、大小跟随；空载电机加纯力矩会持续加速，**不要长时间保持**，用 Kd 或短脉冲。
5. RS10P 从静止起动可能需要 >0.6 N·m（输出端静摩擦），这属于机械特性，不是反馈故障。

### 2.6 停止与记录

1. 点“停止选中（可再次使能）”，等回到 IDLE；确认实际停稳。
2. 测下一台前重新选 ID（**选另一台会把草稿清零，不会复制目标**）。
3. 每台测完点“导出本次 CSV”，记录 ID、型号、增益、指令、实际值、异常。

## 3. 七台整组

1. 先做 **7 台零力矩**：设时长 60 秒，勾选安全确认，点 **“全部使能（零力矩）”**，确认框会列出 ID1–7；等 7 行都 ACTIVE。
2. 零力矩保持 10 秒：看位置/速度是否稳定、温度、有无 FAULT；这一步不应触发任何停机。
3. 小位置：选 ID1，p=当前+0.03，Kp=0.5，Kd=0.1，应用；确认稳定后依次对 ID2–7 重复（每次只改当前选中那台）。
4. 观察 10–20 秒：若出现“全部 FAULT/锁存”，记录发生时的 ID、目标、实际位置，然后复位板子再降幅度重试。
5. 速度整组：7 台都设 Kp=0、Kd=1.0、v=±0.1、τ前馈=0.05；稳定后再到 0.2。
6. 力矩整组：7 台 Kp=Kd=0.5、v=0、τ=±0.1，短脉冲；确认后再加。
7. 停止：单台“停止选中”，或“全部锁存停机 · 需复位”。

> 整组时任何一台异常都会触发全局锁存停机；这是板端保护，不是“全部正常”。复位后重新逐台确认。

## 4. 建议起始参数

| 项目 | RS00（ID1–3） | RS10P（ID4–7） |
| --- | --- | --- |
| 位置 Kp | 1.5–2.5 | 0.5–1.5 |
| 位置 Kd | 0.15–0.3 | 0.1–0.2 |
| 位置阶跃 | 0.05–0.15 rad | 0.05–0.15 rad |
| 速度 Kd | 1.0 | 0.8–1.0 |
| 速度指令 | 0.1–0.3 rad/s | 0.1–0.3 rad/s |
| 速度前馈 τ | 0.1–0.15 N·m | 0.05–0.1 N·m |
| 力矩（空载） | 0.1–0.3 N·m | 0.3–0.5 N·m |

所有值都受界面/板端限制：p ±12.57 rad、v ±1 rad/s、τ ±1 N·m、Kp 0–5、Kd 0–1；GUI 估算力矩 ≤1.95 N·m，板端 ≤2 N·m。

## 5. 出现这些情况立即停

- 位置突然跳变 >0.2 rad、速度异常增大、持续嗡鸣/抖动；
- 电机温度快速上升、出现 FAULT/警告字；
- 板端“全部锁存停机”、串口断开、窗口卡顿 >200 ms（会触发锁存）；
- 电源板电压明显跌落、支路电流异常。

## 6. 异常处理

- **锁存停机**：板子需要复位（窗口顶部“复位开发板（清锁存）”按钮、ST-LINK 复位或重新上电）；复位会让使能中的电机立即失去扭矩（200 ms 看门狗后停），先支撑再复位。复位后重新连接、重新逐台使能。
- **“板端拒绝命令 3”/2 N·m 限制**：目标离当前位置太远或 Kp 太大；先把 p 设到当前值，再小步加。
- **使能失败**：确认该台 IDLE、静止（|v|≤0.1）、有新鲜读数；先停止其他已使能电机再试。
- **位置跳变**：仓库历史里已有记录；记下 ID、UID、时间、增益和原始 CSV，先降低幅度/增益，不要继续加大。

## 7. 记录

窗口自动保存 `nodes.csv`、`wire.bin`、`commands.jsonl`、`session.json` 到
`tools/pico_workbench/logs/robot14-tuning-时间/`。每次换参数/换电机后“导出本次 CSV”，并在文件名或备注里写清 ID、型号、增益和现象。
